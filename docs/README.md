# Builders Clean Brisbane Co. — website kit

Hand this whole folder to Claude Code and ask it to start with `CLAUDE_CODE_PROMPT.md`.

- `CLAUDE_CODE_PROMPT.md` — the build brief (stack, site map, page template, SEO rules, quality bar)
- `docs/` — the business, brand, keyword map, research, 17 service-page briefs, 20 area-page briefs, core pages, blog plan and technical checklist
- `assets/brand/` — logos (SVG and PNG), favicons, OG image, GBP profile and cover images
- `assets/fonts/` — Barlow Condensed (ExtraBold, Bold, SemiBold) with licence
- `assets/photos/web/` — 10 real job photos, JPG and WebP, EXIF stripped
- `assets/photos/branded/` — the same photos with the logo bar, for social and GBP only
- `PLACEHOLDERS.md` — everything the owner still has to supply

Phone, email, prices, insurance amounts and reviews are not in the kit on purpose. Leave them as placeholders until the owner confirms them.
