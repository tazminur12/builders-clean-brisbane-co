# 02 — Keyword map (one primary keyword per page)

**Rule:** every page owns exactly one primary keyword. Secondary keywords and synonyms live in H2s and body copy on that same page. No primary keyword appears as the primary target of two pages. This is how pages avoid cannibalising each other (see the Local SEO Playbook, page 2–3).

**Data note:** Semrush returned no data for this project (no API units), so there are **no exact monthly search volumes**. Tiers below are directional (High / Medium / Low), built from Google's own related searches, competitor title tags and category names. Before launch, confirm volumes in free Google Keyword Planner (set to Australia and Brisbane) and reorder secondary keywords if needed. Do not change the page map unless a keyword turns out to be near zero.

## Keyword cannibalisation check

- "builders clean brisbane" lives only on the homepage. Service pages use their own stage or service term.
- "post construction cleaning brisbane" lives only on its service page. The homepage and blog link to it with that phrase as anchor text, but do not target it as a primary.
- Area pages never target "builders clean brisbane"; they target "builders clean [suburb]".
- Blog posts never target a service primary keyword.
